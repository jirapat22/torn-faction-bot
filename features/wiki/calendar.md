## How Torn's calendar works (how it works)
To see exact dates when events run, visit Torn's Calendar. Some events have moving dates, some have fixed dates, and some events use an Event Time Slot, where the player can choose a starting time between 10:00 and 16:00 TCT. When no active event is running, the player's competition status reflects the Rock, Paper, Scissors status.

## Event Time Slot (choosing your start time)
To improve Torn's performance during high-activity events, players are given a staggered start time. Each player is randomly assigned a time slot between 10:00 TCT and 16:00 TCT in 15-minute increments when their account is created. You can see your event start time at the top of the Calendar page. If you do not like your time slot, you may change it to any other available slot in the drop-down menu, provided it hasn't already been picked by too many other players. Your end time is adjusted to match, so you always get the same 48-hour event duration.

Events with an event time slot: Valentine's Day, St Patrick's Day, Easter Egg Hunt, 420 Day, Museum Day, World Blood Donor Day, World Population Day, World Tiger Day, International Beer Day, Tourism Day, CaffeineCon, Trick or Treat, World Diabetes Day, Slash Wednesday, Christmas Town.

Events without an event time slot (same time for everyone): Awareness Awareness Week, Weekend Road Trip, Employee Appreciation Day, Torn Anniversary, Black Friday. Before time slots (patch 20/02/2024), all events began at exactly 12:00 TCT.

## Community events (Halloween, Christmas, URT)
Halloween and Christmas each bring several weeks of Community Events run by Torn's staff, one of the best times to earn the "Champion" honor bar and other collectibles and awards. URT started as a player-made tournament and became a sanctioned annual event with its own unique prizes. There are also a few rarer daily community events.
